# CollegaPortaal

CollegaPortaal is een lichte, openbare startpagina voor collega's.

De portal verwerkt, bewaart of toont geen inloggegevens, roostergegevens of trafficgegevens.

## Beheer

Voeg alleen algemene, publiceerbare informatie toe. Plaats nooit persoonsgegevens, credentials, roosters of interne operationele data in deze repository.
